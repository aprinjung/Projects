- 제목 : 정형 및 비정형데이터를 활용한 금리예측모델
  
- 목표 : 비정형 데이터의 잠재적 예측 정보(지정학적 리스크 등)를 자연어 처리 기법을 통해 정량화하여 반영한 금리 예측 모델을 개발하고, 금리 변화의 원인을 이해하고 미래 변동을 합리적으로 예측할 수 있도록 하는 인사이트 제공
